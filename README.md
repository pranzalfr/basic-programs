This is my first GitHub repository. It contains simple, beginner-friendly Python programs that cover the fundamentals of programming. I made it to:

## 📚 Topics Covered

- Input and output (`input()`, `print()`)
- Variables and data types
- Operators and expressions
- Conditional statements (`if`, `elif`, `else`)
- Strings
- Lists
- Functions

## ▶️How to Run

1. Make sure Python 3 is installed. Check with:
   ```
   python --version
   ```
2. Download or clone this repository:
   ```
   git clone https://github.com/pranzalfr/basic-programs.git
   ```
3. Go into the folder:
   ```
   cd [python]
   ```
4. Run any program:
   ```
   python filename.py
   ```
