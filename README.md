## ▶️How to Run

1. Make sure Python 3 is installed. Check with:
   ```
   python --version
   ```
2. Download or clone this repository:
   ```
   git clone https://github.com/pranzalfr/basic-programs.git
   ```
3. Go into the folder:
   ```
   cd [python]
   ```
4. Run any program:
   ```
   python filename.py
   ```
